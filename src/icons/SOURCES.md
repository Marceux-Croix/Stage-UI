# Icon sources

Material Symbols Outlined, weight 400, from the npm package `@material-symbols/svg-400@0.47.5`
(https://github.com/marella/material-symbols, which packages
https://github.com/google/material-design-icons). File names are the Material Symbols names;
`-fill` is the filled variant. `build.py` embeds the icons that `template.html` uses as an SVG
sprite in `STYLE_GUIDE.html`.
